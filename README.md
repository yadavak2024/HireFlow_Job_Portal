# HireFlow – Job Portal 🚀

HireFlow is a full-stack job recruitment platform that connects candidates with recruiters. Candidates can search and apply for jobs, while recruiters can post jobs and manage applications through dedicated dashboards.

## 🌐 Live Demo

### Frontend
https://hire-flow-job-portal-green.vercel.app

### Backend API
https://hireflow-backend-ccba.onrender.com

### API Base URL
https://hireflow-backend-ccba.onrender.com/api

---

## ✨ Features

### 👨‍💼 Candidate

- Browse available jobs
- Search jobs by title, company, or skills
- View detailed job information
- Create a candidate account
- Login using authentication
- Apply for jobs
- View submitted applications
- Candidate dashboard

### 🏢 Recruiter

- Create recruiter account
- Login securely
- Post new jobs
- View posted jobs
- Delete jobs
- View candidate applications
- Update application status
- Recruiter dashboard

### ⚡ Platform

- Responsive modern UI
- React Router navigation
- REST API integration
- JWT authentication
- MongoDB database
- Role-based workflows
- Vercel frontend deployment
- Render backend deployment
